# 面板 UI · 样式需求整理

来源：本会话 12 轮反馈（m00001 / m00444 / m00520 / m00751 / m00836 / m00879 / m00996 / m01054 / m01129 等）。
这份文件只记录「你要什么、不要什么」，不记录实现细节；实现见 `docs/mockups/panel-ui.html`。

## 一、总诉求

1. 完全重构，功能逻辑不变，以 `功能清单.md` 为准。
2. 配色、圆角、字号、间距、控件全部取 DSH 自带的那一套；DSH 有现成组件的，必须用现成组件。
3. 不参考当前 UI（`df-*` 那一套），从零开始。
4. 用 HTML 示意稿确认效果，不需要图片。

## 二、明确否掉的（做过、被退回）

| 做过的 | 你的反馈 | 结论 |
|---|---|---|
| 每个分区上下都画 0.5px 线 | 大量分割线，单调 | 结构不能靠线 |
| 大量卡片 + 砖 + 标签同屏 | 拥挤、没有重点、看起来乱 | 层次不能靠盒子 |
| 三块可拖拽面板、左右对比 diff | — | 不做（已写入 proposal） |
| 顶部胶囊分段控件 | 顶部 tab 不好看 | 不用 `SegmentedTabs` 做页导航 |
| 三个 20px 数字浮在空白里 | 指标区不好看 | 数字必须有锚点 |
| 展开态「高亮行 + 详情卡」两层灰 | 展开收起看着奇怪 | 一条记录只有一个表面 |
| 槽位两列砖网格 | 看着累、乱 | 格子里内容一多，行高必然参差 |
| 槽位缩进 + 竖轨 | 竖线敷衍 | 不能用线表达归属 |
| 只调大间距来分区 | 不够明显，看久了累 | 只靠留白也不成立 |
| 每个区域铺整幅底色带 | 看着很奇怪 | 整屏铺带会让所有区域等权 |

## 三、要的（正面要求）

1. **区域边界要一眼看得出**，但不能用线、不能用卡片、不能整屏铺底色。
2. **每页要有主角**：一处 22px 的数字，或一处展开/编辑的表面，不要哪都在喊。
3. **UI 种类要够**：行、砖、数字、点、标签、条、表单，别一屏只有一种行。
4. **要安静**：正文 13、元信息 12、等宽 11，字重不超过 500，颜色只给状态。
5. **要能扫读**：一屏能看出「跑了几件事、哪里卡住、哪个仓库出问题」。
6. **两种主题都要成立**：浅色下 `bg-layer-1/2/3` 全是纯白，因此不能依赖描边分层。

## 四、由此得出的结构结论（v4）

1. **一列账本**：左侧 84px 固定标签列写「这是哪一块」（指标 / 项目 / 未完成 / 调度 / 开发 / 验收 / 仓库名 / 组名 / 字段名），右侧内容列写「里面有什么」。区域靠标签列的位置 + 22px 留白分开，不画线、不铺底色。
2. **上下文强的页面换标签语义**：槽位页的标签列就是仓库名，基线页就是组号 + 组名，代理页就是运行 / 主会话 / 子代理。
3. **全屏唯一的容器**：展开的任务详情、基线的编辑表单。它用 `bg-module-platform` + R12，是页面上唯一"抬起来"的东西。
4. **零件五种**：行（42 / 24px）、砖（22px）、焦点块、状态点与标签、3px 进度条。一页只用两三种。
5. **零分割线**：唯一保留的是底部确认条上沿（它是工具条，不是分组）。
